```markdown
# 📊 Auditoría del Sistema — InventarioTI

El sistema registra todas las acciones importantes.

## Acciones auditadas

- Login exitoso
- Login fallido
- Crear
- Actualizar
- Eliminar
- Asignar dispositivo
- Devolver dispositivo

## Campos registrados

| Campo    | Descripción             |
| -------- | ----------------------- |
| Usuario  | Quién realizó la acción |
| Acción   | Tipo de acción          |
| Fecha    | Fecha y hora            |
| IP       | Dirección IP            |
| Endpoint | Ruta del endpoint       |
| Datos    | Información afectada    |

## Ubicación del código

La auditoría se ejecuta en:

- Services
- Helpers
- LoginController

## Objetivo

- Trazabilidad
- Seguridad
- Control institucional
```
